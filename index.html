▤ Prateleira

Objetivo

Arraste as imagens entre as prateleiras para que cada par de imagens iguais fique lado a lado na mesma prateleira.

Um par só conta quando as duas imagens ocupam slots vizinhos. Um espaço vazio no meio quebra o par.

Como jogar

  • Toque e arraste uma imagem para movê-la.
  • Solte sobre a prateleira de destino — ela vai para o slot vago mais próximo.
  • Slots vagos aparecem com contorno azul pontilhado.
  • O traço azul embaixo indica que o par está formado.

🎨 Temas

Cada fase usa um tema sorteado: Animais, Comidas, Empresas, Ferramentas, Músicas ou Veículos.

As imagens são sorteadas do tema do dia.

Pontuação

  • Par normal: +10
  • Bônus de fase: +50
  • Bônus de tempo: +2/s restante

〜 Fios

Objetivo

Arraste os nós para desembaraçar os fios até que nenhum cruze com outro.

Como jogar

  • Toque e arraste os nós internos para mover o fio.
  • Um fio fica azul brilhante quando está completamente limpo.

⚡ Fio Elétrico (+100 pontos)

Um dos fios pode ser dourado com ⚡. Vale 5× mais.

  • Aparece a partir do nível 5 (30% de chance).

Pontuação

  • Fio normal limpo: +20
  • Fio elétrico limpo: +100
  • Bônus de fase: +100
  • Bônus de tempo: +2/s restante

🗄 Gaveta

Objetivo

Arraste imagens entre as gavetas até que cada gaveta contenha apenas um tema.

Os temas são: Animais, Comidas, Empresas, Ferramentas, Músicas e Veículos.

Como jogar

  • Toque e arraste uma imagem para movê-la entre gavetas.
  • Solte sobre uma gaveta — ela vai para o primeiro slot vago.
  • Quando uma gaveta fica com um único tema, ela brilha em verde-sálvia.

Pontuação

  • Mover para a gaveta correta: +5
  • Completar uma gaveta: +20
  • Bônus de fase: +50
  • Bônus de tempo: +2/s restante
